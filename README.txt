Tessie for Tesla (Homey)

Control Tesla vehicles in Homey via Tessie.

Features
- One Tesla vehicle per Homey device
- Pair all vehicles from your Tessie account
- Climate controls: start/stop and cabin temperature
- Seat heating and seat cooling via Flow actions
- Steering wheel heater via Flow actions
- Charge controls: start/stop charging and open charge port
- Vehicle controls: wake, lock/unlock, frunk, trunk
- Configurable polling (default 60s)
- Retry handling for commands
- Repair flow to update Tessie access token

Setup
1) Open app settings and paste your Tessie access token.
2) Optionally configure polling interval and retry attempts.
3) Pair Tesla devices from the app.

Notes
- This app uses an app-wide Tessie access token.
- Internet connection is required.
